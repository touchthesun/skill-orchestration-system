# User Stories

This document outlines key user stories that the DoIT Skills Orchestration System must support. These stories help ensure the system meets the real needs of cloud professionals and the organization.

## Cloud Professional User Stories

### Career Development

1. **As a** cloud architect,  
   **I want to** ask what skills are most in-demand right now,  
   **So that** I can prioritize my learning time effectively.

2. **As a** Kubernetes administrator,  
   **I want to** see which upcoming projects match my current skill set,  
   **So that** I can contribute where I'll be most effective.

3. **As a** data engineer,  
   **I want to** understand which certifications would best complement my current skills,  
   **So that** I can advance my career in alignment with company needs.

4. **As a** cloud support engineer,  
   **I want to** see which ticket categories have been increasing in volume,  
   **So that** I can develop expertise in emerging problem areas.

5. **As a** mid-level engineer,  
   **I want to** ask "What skills do senior engineers in my role typically have that I'm missing?",  
   **So that** I can plan my path to promotion.

6. **As a** FinOps specialist,  
   **I want to** see which cloud platforms are growing most rapidly in our client base,  
   **So that** I can focus my learning on those environments.

### Project Alignment

7. **As a** cloud architect,  
   **I want to** ask "Which upcoming projects need someone with my skills?",  
   **So that** I can find opportunities to apply my expertise.

8. **As a** project team lead,  
   **I want to** ask "Who has experience with both Kubernetes and Azure DevOps?",  
   **So that** I can staff my project appropriately.

9. **As a** technical mentor,  
   **I want to** see which junior staff members have complementary skill gaps,  
   **So that** I can efficiently organize group training sessions.

### System Interaction

10. **As a** non-technical user,  
    **I want to** interact with the system using natural language,  
    **So that** I don't need to learn a complex interface.

11. **As a** privacy-conscious employee,  
    **I want to** understand what data is being used to generate recommendations,  
    **So that** I can trust the system's suggestions.

## Management User Stories

12. **As a** pod manager,  
    **I want to** see skill distribution across my team,  
    **So that** I can identify coverage gaps and redundancies.

13. **As a** strategic planner,  
    **I want to** indicate future skill priorities for the company,  
    **So that** employees can align their development with strategic goals.

14. **As a** client services director,  
    **I want to** analyze the correlation between skill acquisition and ticket resolution metrics,  
    **So that** I can measure the ROI of learning incentives.
